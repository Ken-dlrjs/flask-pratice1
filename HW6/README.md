## 단계 ③ 답

총액은 수량 × 단가라는 **곱셈**인데, linear regression은 각 열에 계수를 곱해 **더하는** 직선 모양만 만들 수 있어 곱셈을 흉내만 낸다. 그래서 test R²가 0.862에 그친다.
qp = 수량 × 단가 열을 더하면 총액이 qp에 대한 직선(계수 [0, 0, 1], 절편 0, 즉 「총액 = qp」)이 되므로, model을 바꾸지 않고 feature 하나만으로 test R²가 1.0이 된다.

## 단계 ⑤ 결정과 이유

**max_depth 8**을 고른다. cross-validation(cv=5) 평균이 depth 8은 0.992(std 0.000), depth 12는 0.995, 제한 없음은 0.994로 0.003 이하 차이밖에 안 나는데, 잎 수는 250개 대 781 · 800개로 depth 8이 훨씬 단순하다. score가 거의 같으면 단순한 쪽을 고른다.
training 1.000과 test 0.994의 차이가 작은 것은 이 문제에 규칙(총액 = 수량 × 단가)이 실제로 있어서, 깊게 외워도 overfitting으로 해롭지 않기 때문이다.

## 단계 ⑦ 답

API에는 **linear regression + qp**를 올렸다. 수량 40 · 단가 200,000을 넣으면 linear + qp는 **8,000,000**으로 실제 곱(**8,000,000**)과 정확히 같지만, tree(depth 8)는 **7,362,301**로 약 64만 원이 틀린다. tree는 training에서 본 값들을 계단처럼 흉내 낼 뿐이라 큰 주문처럼 범위 밖의 값은 맞히지 못하고, linear + qp는 공식 자체를 찾았기 때문이다.
